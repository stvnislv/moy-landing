# Telegram Mini App Stvnislv

Мини-приложение-визитка внутри Telegram. Описано в `../brief.md`, раздел 11: четыре экрана, внизу меню из четырёх кнопок, оформление как на сайте (`../index.html`). Чистые HTML, CSS и JavaScript, без фреймворков и без сборки.

## Файлы

| Файл | За что отвечает |
|---|---|
| `index.html` | Точка входа. Каркас: четыре `<section class="screen">`, нижнее меню `.tabbar`, всплывающее сообщение `.toast`. Подключает Telegram SDK (`telegram-web-app.js`) и до отрисовки ставит тему, чтобы экран не мигал. |
| `data.js` | **Все тексты, цены, сроки, контакты и работы** — объект `window.APP_DATA`. |
| `app.js` | Telegram SDK (тема, имя пользователя, кнопка «Назад», вибрация, ссылки), заполнение экранов из `data.js`, переходы между экранами. |
| `portrait.js` | Портрет из нитей с нейронами и сердцем — копия кода с сайта. Данные `PORTRAIT` встроены (сделаны из `../portrait-cut.png`). Отдаёт `window.portrait.refresh()`. |
| `styles.css` | Все стили: цвета дня и ночи, стекло, кнопки, меню, экраны. |
| `fonts/geist-*.woff` | Шрифт Geist 300/400/500, извлечён из `@font-face` в `../index.html`. |

## Экраны и навигация

| Экран | `data-screen` / `id` | Содержимое |
|---|---|---|
| Главная | `home` | Приветствие по имени из Telegram, щель со светом, портрет, имя, фраза. |
| Услуги | `services` | Карточки «Лендинг», «Сайт-визитка», «Telegram-приложение»: срок, цена «от», кнопка «Обсудить». |
| Портфолио | `portfolio` | Первым — сайт, потом это приложение, в конце приглашение «Обсудить». |
| Связаться | `contact` | Кнопка «Написать мне в Telegram», Telegram/Instagram/почта, четыре шага работы. |

- Переход — функция `show(name)` в `app.js`. Старый экран уходит в сторону и гаснет (200 мс), новый въезжает с другой стороны (260 мс). Направление зависит от порядка в массиве `order` — он совпадает с порядком кнопок меню.
- Повторное нажатие на активную кнопку меню прокручивает экран наверх.
- Кнопка «Назад» в шапке Telegram видна на всех экранах, кроме «Главной», и возвращает на неё.
- Открыть сразу нужный экран: в Telegram — `?startapp=services` в ссылке на приложение, в браузере — `index.html#services`.
- Если включено «уменьшение движения», переходы и анимации выключены, портрет стоит.

**Новый экран:** добавить `<section class="screen" id="…" data-screen="…" hidden>` в `index.html`, кнопку `<button class="tab tap" data-tab="…">` в `.tabbar`, имя в массив `order` в `app.js`. Меню рассчитано на четыре кнопки: при пяти поменять `repeat(4, 1fr)` и ширину `.tab-glow` в `styles.css`.

## Где менять данные

- Тексты, цены, сроки, контакты, работы — только `data.js`. Цена — число рублей, `от … ₽` добавляется само.
- Новая работа — объект в `portfolio`: `title`, `description`, `tags`, `preview` (`"site"` или `"app"` — миниатюры нарисованы в CSS), `url` (если есть — появится кнопка «Открыть сайт»).
- Цены и тексты на сайте лежат отдельно, в объекте `site` в `../index.html`. При изменении прайса обновлять оба места и `../brief.md`.

## Telegram

- Тема берётся из Telegram: `colorScheme === "dark"` → класс `night` на `<html>` («тёмный титан» с сайта). Цвета темы Telegram не используются — оформление как на сайте. Шапка и низ окна Telegram красятся в цвет фона.
- Вне Telegram тема следует системной (`prefers-color-scheme`), SDK не обязателен: приложение открывается и в обычном браузере, и без интернета (кроме самого SDK).
- Ссылки на Telegram открываются через `openTelegramLink`, остальные — через `openLink`. Почту ссылкой `mailto:` из Telegram не открыть, поэтому по нажатию адрес копируется.
- Кнопки «Обсудить» подставляют в чат готовый текст (`message` в `data.js`) через `?text=`.

## Публикация и проверка

- Netlify копирует папку в `_site/tg-app/` (команда в `../netlify.toml`), этот файл не публикуется. Адрес после публикации: https://stvnislv.netlify.app/tg-app/
- Подключение к боту: в @BotFather — `/newapp` (или Menu Button у бота) и этот адрес. Делает владелец.
- Проверка: открыть `index.html` в Chrome, включить режим устройства (DevTools → Toggle device toolbar) с шириной 320, 375 и 430 px. Тёмную тему — через DevTools → Rendering → `prefers-color-scheme: dark`. Режим без анимаций — флаг `--force-prefers-reduced-motion`.
- Правила для git — как во всём проекте (`../CLAUDE.md`): коммит без push, публикация только по слову «публикуй».
