## 3. Что взять у augen.pro

Значения взяты прямо из CSS сайта.

| Что | На augen.pro | Вывод для нас |
|---|---|---|
| Фон | `--color-offWhite: #f2f2f4`, светло-серый с лёгкой холодной ноткой | этот же фон: он не белый, и на нём видно стекло |
| Текст | `--color-greyDark: #1d1e20`, не чистый чёрный | основной цвет текста |
| Акцент | `--color-blue: #0071e3`, единственный яркий цвет на странице | кнопки, ссылки, инициалы, фокус |
| Шрифт | PP Neue Montreal: платный гротеск, без кириллицы в свободном доступе | нужна замена с кириллицей и тонкими начертаниями |
| Заголовки | огромные: `clamp(8rem, 9.7vw, …)`, вес 300, межстрочный интервал 0.9 | крупный тонкий заголовок на первом экране — главный приём страницы |
| Основной текст | вес 350, межбуквенный интервал −0.02em, интервал 1.2 | плотный, слегка сжатый текст; для русского интервал побольше (1.5), иначе тяжело читать |
| Скругления | кнопки-«пилюли» (`border-radius: 6.3rem`), карточки около 1rem | кнопки и меню — пилюли, карточки скруглены умеренно |
| Полупрозрачность | `#ffffff1a`, `#fff3`, `#1d1e2080` — плашки с прозрачностью | подтверждает выбор стекла, но у нас оно должно быть заметнее |

Что брать **не нужно**:
- нумерацию пунктов меню и блоков (`01 Wearable`, `0.1 Our Mission`). У augen это часть фирменного стиля, а у нас разделы не идут по порядку шагов, и номера стали бы украшением без смысла;
- большие фото-обложки: фото пока нет;
- сложное меню с подменю: у нас всего 3–4 раздела.

## 4. Liquid Glass: как сделать и не испортить читаемость

Стекло — это полупрозрачная белая подложка с размытием того, что под ней:

```css
background: rgb(255 255 255 / 0.55);
backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgb(255 255 255 / 0.7);           /* тонкая светлая обводка */
box-shadow: inset 0 1px 0 rgb(255 255 255 / 0.8),   /* блик сверху */
            0 8px 32px rgb(29 30 32 / 0.08);        /* мягкая размытая тень */
```

Выводы:
1. **На ровном сером фоне стекло не видно**: размывать нечего. Под ним нужен мягкий цветной слой: два-три больших размытых пятна, синее и белое, закреплённых за страницей. Тогда при прокрутке меню «плывёт» над ними и выглядит как стекло.
2. **Читаемость:** прозрачность подложки не ниже 55%, текст тёмный `#1d1e20`. Синяя кнопка — сплошная, а не стеклянная: на ней белый текст, и он должен читаться (контраст `#0071e3` с белым около 4.6:1, это уровень AA).
3. **Safari** требует `-webkit-backdrop-filter`. Если браузер не умеет размывать, подложку делаем почти непрозрачной (`@supports not (backdrop-filter: …)`).
4. **Не перебарщивать:** стекло только у шапки, второстепенных кнопок, карточек услуг и блока контактов. Обычный текст разделов лежит прямо на фоне.

## 5. Шрифт

Нужен гротеск с кириллицей и весами от 200 до 600, бесплатный и доступный в `next/font/google`.

- **Onest** — выбран. Современный гротеск с хорошей кириллицей (его делали для русскоязычных интерфейсов), веса 100–900. По характеру ближе всего к Neue Montreal: геометрия без лишней строгости.
- Manrope и Inter — отклонены. Тонкие веса у них есть, но это самые частые шрифты в шаблонных сайтах, и страница выглядела бы «как все».

Одна гарнитура на всё: заголовки весом 300, текст 400, кнопки 500.

## 6. Как сделать сайт максимально простым

- Одно действие на всю страницу: «Написать в Telegram». Кнопка везде одинаковая — одного цвета и с одной надписью.
- В меню три ссылки: «Обо мне», «Услуги», «Контакты». Плюс кнопка «Написать».
- Тексты короткие, без жаргона («ИИ», а не «LLM»; «сайт за несколько дней», а не «быстрый time-to-market»).
- Цена сразу на карточке, крупно, без «узнать цену».
- Кнопки крупные: высота от 48px, чтобы легко попадать пальцем.
- Анимации: одна плавная анимация появления первого экрана, а не выезд каждого блока. Если в системе включено «уменьшение движения», анимацию отключаем.

## 7. Дизайн-план

**Цвета**

| Токен | Значение | Роль |
|---|---|---|
| `bg` | `#F2F2F4` | фон страницы |
| `ink` | `#1D1E20` | основной текст |
| `muted` | `#5F626A` | второстепенный текст (контраст с фоном около 5.5:1) |
| `accent` | `#0071E3` | кнопки, ссылки, инициалы |
| `accent-hover` | `#0062C4` | наведение на кнопку |
| `glass` | `rgb(255 255 255 / 0.55)` + размытие | шапка, карточки, второстепенные кнопки |

**Типографика:** Onest. Заголовок первого экрана — `clamp(2.75rem, 8vw, 7.5rem)`, вес 300, интервал 0.95, межбуквенный −0.03em. Заголовки разделов — `clamp(2rem, 4.5vw, 3.5rem)`, вес 300. Текст — 1.0625rem, вес 400, интервал 1.55, строка не длиннее 65 символов.

**Раскладка:** всё выровнено по левому краю, ширина до 1200px.

```
┌─( имя ·········· Обо мне  Услуги  Контакты  [Написать] )─┐  стеклянная шапка-пилюля
│                                                          │
│  Имя Фамилия:                                            │
│  сайты и лендинги                                        │  огромный тонкий заголовок
│  с помощью ИИ                                            │
│  Подзаголовок о пользе                                   │
│  [ Написать в Telegram ]                                 │
│                                                          │
│  Обо мне        ( ИФ )   абзацы                          │
│                                                          │
│  Услуги   [стекло] [стекло] [стекло]                     │  на телефоне карточки в столбик
│                                                          │
│  ┌──────── стеклянная панель контактов ──────────┐       │
│  │ Обсудим ваш сайт?   [ Написать в Telegram ]   │       │
│  └───────────────────────────────────────────────┘       │
│  имя · год · Telegram                                    │
└──────────────────────────────────────────────────────────┘
```

**Принципы**
1. Главный приём один — огромный тонкий заголовок на первом экране. Всё остальное спокойное.
2. Стекло показывает, что можно нажать или где лежит важное. Оно не используется для украшения.
3. Синий цвет только у действий и у инициалов в круге.

**Проверка плана на шаблонность.** Сначала план выглядел как типичный SaaS-набор: три одинаковые карточки с серой тенью и подпись над каждым заголовком. Что изменено:
- подписи над заголовками убраны;
- номера 01/02/03 не используются;
- у карточек услуг цена вынесена вниз и набрана крупнее названия, чтобы читалась первой;
- тень мягкая и голубоватая, а не стандартная `rgba(0,0,0,.1)`;
- стрелки «→» на кнопках не используются.
