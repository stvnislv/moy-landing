# Сайт-визитка эксперта по разработке с ИИ: спецификация

Дата: 2026-10-26
Проект: my-lending

## Кратко

Одностраничный сайт-визитка специалиста, который делает сайты и лендинги с помощью ИИ.
Сайт рассказывает, кто он и что делает, и ведёт посетителя к одному действию: написать в Telegram.

## Проблема

У специалиста нет места, куда можно отправить потенциального клиента.
Портфолио и отзывов пока нет, поэтому сайт должен вызывать доверие за счёт ясного предложения,
понятных цен и собственного качества: сам сайт и есть первый пример работы.

## Критерии успеха

- Посетитель за 5 секунд понимает: кто это, что он делает, как с ним связаться.
- Кнопка «Написать в Telegram» видна на первом экране и в конце страницы.
- Сайт хорошо выглядит и работает на телефоне и на компьютере.
- Свои данные (имя, Telegram, цены) можно поменять в одном файле, не трогая вёрстку.

## Для кого сайт

- **Частные клиенты**: эксперты, мастера, фрилансеры, которым нужен свой сайт или лендинг.
- **Бизнес**: небольшие компании и предприниматели, которым нужен лендинг под услугу или акцию.
- Уровень: не технические люди. Тексты простые, без жаргона.

## Путь посетителя

1. Открывает ссылку (из Telegram, соцсетей, переписки).
2. Первый экран: имя, кем является, одна фраза о пользе, кнопка «Написать в Telegram».
3. Прокручивает до «Обо мне»: коротко, кто он и почему работает с ИИ (быстрее и дешевле).
4. «Услуги»: видит карточки услуг с ценой «от ... ₽».
5. «Контакты»: ещё раз кнопка Telegram.
6. Нажимает кнопку, открывается чат в Telegram (`https://t.me/<username>`).

## Требования

### Обязательно (P0)

- **Одна страница** с плавной прокруткой к разделам.
- **Шапка**: имя или логотип-текст слева, ссылки на разделы, кнопка «Написать» справа. На телефоне меню прячется под кнопку-гамбургер.
- **Первый экран (Hero)**:
  - заголовок: «Имя Фамилия: сайты и лендинги с помощью ИИ» (заглушка);
  - подзаголовок с пользой: быстро, современно, по понятной цене;
  - основная кнопка «Написать в Telegram».
  - Готово, когда кнопка видна без прокрутки на экране 375×667.
- **Обо мне**: место под фото (заглушка-круг с инициалами, пока фото нет), 2–3 коротких абзаца.
- **Услуги**: 3 карточки, у каждой название, 1–2 строки описания и «от ... ₽»:
  1. Лендинг (одна продающая страница);
  2. Сайт-визитка (как этот);
  3. Доработка или редизайн существующего сайта.
- **Контакты**: заголовок-призыв, кнопка Telegram, подпись «Отвечаю в течение дня» (заглушка).
- **Подвал**: имя, год, ссылка на Telegram.
- **Все личные данные в одном файле** `src/config/site.ts`: имя, должность, username в Telegram, тексты, услуги и цены.
- **Адаптивность**: телефон (от 360px), планшет, компьютер.

### Желательно (P1)

- **Раздел «Работы» заложен, но скрыт**: компонент есть, в конфиге флаг `showPortfolio: false`. Когда появятся проекты, они добавляются в конфиг, флаг ставится в `true`.
- Лёгкие анимации появления блоков при прокрутке (без перегруза).
- Мета-теги: title, description, картинка для превью ссылки (Open Graph).
- Иконка сайта (favicon).

### Можно позже (P2)

- Разделы «Как я работаю» и «Вопросы и ответы».
- Форма заявки с отправкой в Telegram.
- Публикация в интернете (Vercel) и свой домен.

## Дизайн

- **Тёмный, технологичный**: тёмный фон (почти чёрный, не чистый #000), светлый текст, один яркий акцентный цвет для кнопок и выделений.
- Современный шрифт без засечек, крупные заголовки, много воздуха.
- Без шаблонного вида: следовать навыку **frontend-design**.
- Кнопки Telegram заметные, одного стиля по всему сайту.

## Техническое устройство

- **Next.js** (App Router) + **TypeScript** + **Tailwind CSS**.
- Без базы данных и без сервера: все данные в `src/config/site.ts`.
- Компоненты по разделам: `Header`, `Hero`, `About`, `Services`, `Portfolio` (скрыт), `Contacts`, `Footer`.
- Структура:
  ```
  src/
  ├── app/          # layout.tsx, page.tsx, globals.css
  ├── components/   # разделы сайта
  └── config/
      └── site.ts   # все тексты и контакты
  ```
- Запуск: `npm run dev`, открыть http://localhost:3000.

## Безопасность и данные

- Сайт не собирает данные посетителей: форм и аналитики на первом этапе нет.
- На сайте публикуются только имя и Telegram, которые владелец сам укажет.

## Нефункциональные требования

- Быстрая загрузка: страница статическая, картинки оптимизированы через `next/image`.
- Доступность: контрастный текст на тёмном фоне, у кнопок понятные подписи.
- Работает в последних версиях Safari, Chrome и Firefox, на iPhone и Android.

## Не входит в работу

- Портфолио и отзывы (пока нет материалов).
- Форма заявки, оплата, личный кабинет, блог.
- Публикация в интернете и домен.
- Многоязычность (только русский).

## Что уточнить при разработке

- Настоящие имя, фамилия, username в Telegram, фото.
- Цены «от ... ₽» для каждой услуги.
- Акцентный цвет: предложить 2–3 варианта на выбор.

## Как использовать эту спецификацию

1. Положите этот файл в проект: `thoughts/shared/specs/2026-10-26-sayt-vizitka.md`.
2. В чате Claude Code в VS Code напишите:
   «Сделай сайт по спецификации thoughts/shared/specs/2026-10-26-sayt-vizitka.md. Используй навыки frontend-design и fullstack-developer».
3. Запустите `npm run dev`, проверьте сайт и попросите исправить, что не нравится.
